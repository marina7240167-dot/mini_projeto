# linha norte

Loja de roupas criada com Flask, Jinja2 e Bootstrap.

## Paginas

- Inicio: destaque da colecao e produtos da semana.
- Catalogo: lista de produtos organizada por categoria.
- Sobre a marca: proposta e valores da linha norte.

## Como executar

```bash
pip install -r requirements.txt
python app.py
```

Depois, acesse `http://127.0.0.1:5000`.

## Tecnologias usadas

- Flask para as rotas e a aplicacao web.
- Jinja2 com template base, heranca, `for` e `if`.
- Bootstrap para navbar, grid responsivo e componentes de layout.
